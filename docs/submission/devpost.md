## Inspiration

Alberta's unemployment rate is 7.3%, against 6.7% for Canada (Statistics Canada, October 2026). People changing careers are told to "upskill", but nobody tells them which skills a real job needs, in what order, or how to show an employer they actually have them. Certificates show you finished a course, not that you understood it. We wanted a way to learn exactly what one real job asks for, and to come away with proof that someone else can check.

## What it does

1. **Start from a real job.** Paste a job posting, upload a PDF, or name a topic. OryxLearn builds an interactive skill map: a dependency graph of 10 to 14 skills, with foundations first. Every skill cites where it came from: an exact quote from the posting, or a quote and page number from the PDF. Code checks every quote against the source, and an unverified quote is never shown as a citation.
2. **Prove each skill by teaching it back.** Explain the skill in your own words, by typing or by voice. A skill stays locked until the skills it depends on are proven.
3. **Grading you can audit.** The AI does not invent a score. For each checkpoint it must quote the learner's own words, code checks that every quote really appears in the answer, and code computes the score. The AI then asks one **live follow-up question about what you just wrote**, and passing it is required. It can ask the question aloud and listen to a spoken answer.
4. **Study tools in every skill.** Flashcards (Space to flip) and a multiple-choice quiz (keys 1-4), generated by Gemini, saved per skill, and citing the posting when the quote is verified. A spaced-repetition review queue (SM-2) brings cards back when they are due. *(confirm)*
5. **Evidence an employer can check.** A public evidence page with a QR code shows what you proved: what you wrote, the verified quotes, the follow-up, integrity signals (pasted or typed, active time) and sources. It is fingerprinted so it can be re-checked without any AI.
6. **Learn with other people.**
   - **Courses:** publish your map as a course, browse other people's, like them, and start your own copy.
   - **Study circles:** a group learns one map together, joining with a QR code and seeing progress live.
   - **People:** find mentors who have *proved* the skills you're still learning, and peers learning the same ones. Matching uses verified progress, not self-reported skills. *(confirm)*
7. **Local and real data.** Alberta labour numbers come live from Statistics Canada. Nothing is invented: if a source is down, the page says so.
8. **Trust and access.**
   - **No login wall.** Guests can do everything. Optional sign-in (Auth0) keeps your work on every device.
   - **Delete my data** removes everything you made.
   - A **trust page** explains what the AI decides and what code checks.
   - An accessible learning mode and read-aloud are built in.

## How we built it

- **Next.js 16** (App Router) with React 19, TypeScript and Tailwind. The repository is organised **by feature** ("vertical slices"): each feature folder owns its UI, server code, tests and README, and features talk only through a small public API. This let two people and their AI tools work in parallel without stepping on each other.
- **AI:** gpt-oss-120b through a fallback chain (Cerebras, Groq, Vercel AI Gateway, Gemini, AWS Bedrock). Flashcards and quizzes ask **Gemini** first. Every model reply is validated in code (zod), and every quote is checked against the source text.
- **Voice:** Deepgram Flux for live transcription and the spoken follow-up. *(confirm: ElevenLabs too?)*
- **Sign-in:** Auth0 with an Authorization Code + PKCE flow, written by hand against the standard. Signing in links your guest work to your account, so no data is moved.
- **Storage and hosting:** a small document store with S3, Vercel Blob or memory drivers; AWS (ECS and S3) and Vercel.
- **Testing:** 1,000+ automated tests. Every feature was reviewed by an independent adversarial reviewer before merging, and checked in a real headless browser, including axe accessibility checks.

## Challenges we ran into

- **AI that grades too kindly.** Asking a model to "score this answer" gave fluent but empty answers 55-85/100. Switching to quote-based checkpoints, verified by code, dropped those to 0-25. On our 71-case eval: 98.6% agreement with the labels and 0 false passes. *(The labels were written by AI and still need a human spot check; we say so on the trust page.)*
- **Rate limits.** Free AI tiers allow about 5 requests a minute. Nothing is generated when a panel opens. Every result is saved once per skill and shared, and demo content is generated in advance.
- **Privacy by default.** Maps are private until published. A private course, its flashcards and its quiz all answer "not found" to strangers, exactly like a missing one, so nobody can tell they exist.

## Accomplishments that we're proud of

- A grade you can audit: every point is tied to a quote from the learner's own words, checked by code.
- Evidence pages that anyone can re-verify without trusting our AI.
- Real, live public data (Statistics Canada), with nothing made up. Demo profiles and sample postings are labelled as such everywhere.

## What we learned

- Let code decide what code can check, and use the AI only to point at evidence.
- A feature-based repository with written contracts between features made AI-assisted pair work much faster and safer.

## What's next for OryxLearn

- More input types (course syllabi, apprenticeship standards) and French support.
